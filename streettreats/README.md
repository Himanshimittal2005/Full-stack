🍽️ StreetTreats

StreetTreats is a modern front-end web project showcasing a street food–themed interface with a clean UI and responsive design. The project is built to practice component-based development, styling, and layout techniques using modern web technologies.

📌 Features

Responsive and user-friendly UI
Clean component structure
Modern styling and layout
Easy to customize and extend
Beginner-friendly project structure

🛠️ Tech Stack

HTML5
CSS3
JavaScript
React (Vite) 
Bootstrap / MUI
